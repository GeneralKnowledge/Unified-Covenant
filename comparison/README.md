# Comparative phase (Phase 5)

This directory holds **structured comparison** across Judaism, Christianity, and Islam after the four-chapter historical chronicle, and—beginning in **Phase 6**—the first **constructive** constitution draft. Comparison documents remain **merge-resistant** where incompatibilities are real; [unified-covenant-v0.1.md](./unified-covenant-v0.1.md) does **not** replace [THE_UNIFIED_COVENANT.md](../THE_UNIFIED_COVENANT.md) (original essay, unchanged).

## Purpose

The chronicle ([history/README.md](../history/README.md)) reconstructs each tradition’s emergence on its own historical terms. The comparison phase asks:

- What do the traditions **share** (with evidence for historical connection where available)?
- Where do they **differ** in belief, practice, and self-understanding?
- Which differences are **directly incompatible** if taken in the same sense at the same time?
- What remains **uncertain** because sources, methods, or chronicle coverage are insufficient?

A future synthesis experiment—if pursued—must be able to **see** real incompatibilities in this matrix, not erase them.

## Evidence labels

The same labels used in historical chapters apply to matrix cells. A single cell may need **more than one label** when it mixes claim types (state which phrase each label qualifies).

| Label | Use in comparison |
|-------|-------------------|
| **Well established** | Strong convergent historical evidence |
| **Widely accepted interpretation** | Substantial scholarship; reconstruction-dependent |
| **Contested** | Meaningful scholarly disagreement |
| **Religious tradition** | A tradition’s theological or scriptural claim (not automatically independent history) |
| **Unknown / speculative** | Insufficient evidence for confidence |

## Comparison dimensions (do not conflate)

Each matrix row should be read with these distinctions in mind:

1. **Historical claim** — What historians can reconstruct about communities, texts, or events.  
2. **Tradition’s own claim** — What a religion teaches about God, revelation, authority, or history.  
3. **Scholarly interpretation** — Academic reconstruction (may be **Contested**).  
4. **Comparative observation** — Carefully stated similarity, difference, or relationship between traditions.

In the **disagreement register**, multi-layer disputes (especially crucifixion/resurrection) are split where needed:

- **Historical reconstruction** — What convergent evidence supports (e.g. crucifixion under Pilate: **Well established** in the chronicle).  
- **Text and interpretation** — What a source says and how communities read it (e.g. Q. 4:157: **Contested** between Muslim, Christian, and academic readers).  
- **Theological claims** — What traditions affirm (**Religious tradition**).  
- **Incompatibility** — Whether claims conflict if taken in the same sense.  
- **Epistemic priority** — Which sources a community treats as decisive (does **not** downgrade a separate historical conclusion).

**Relationship types** (see matrix “Relationship” column):

- **Shared inheritance** — Identifiable historical connection (texts, practices, ideas).  
- **Historical contact** — Communities interacted or influenced one another.  
- **Structural similarity** — Comparable forms; direct borrowing **not** assumed.  
- **Different interpretation** — Related figures or concepts, divergent meaning.  
- **Direct disagreement** — Claims cannot all be true in the same sense at once.  
- **Unresolved** — Evidence or comparison method inadequate.

## How to use the matrix

- Follow **Sources** links to chapter sections; treat the chronicle as a **working** foundation, not infallible authority.  
- When a cell says *n/a* or *inadequately covered*, that is intentional—do not fill gaps with unsourced assertions.  
- Report errors or missing registry entries by extending [sources/registry.md](../sources/registry.md) in a focused follow-up, not by silently rewriting historical chapters.

## Qualifying “the tradition”

Matrix cells often name **dominant or normative** positions for a period covered by the chronicle. They do **not** imply every adherent held the same view, or that minority interpretations have equal institutional standing. Internal diversity (Pharisees/Sadducees; early Jewish Jesus-followers vs. other Jews; Sunni/Shi‘i memories in **Ch.4**) is noted where the chronicle supports it.
