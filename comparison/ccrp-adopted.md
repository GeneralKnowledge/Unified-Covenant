## Anti-circularity

The Constitution **cannot** settle a scriptural dispute by citing **only** its own supremacy clause. UC **B** text is **not** independent proof of historical **H** or inherited **R** claims.

---

## 1. Ruling status (mandatory at opening)

Decompose each dispute into sub-questions **q1…qn**. Assign **one RS code per sub-question**.

| Code | Meaning | CCRP behaviour |
|------|---------|----------------|
| **RS-1** Settled **B/H** | **MD-01–MD-11**, **§14 DR-***, or prior **§12** **B**/**H** | **Do not** re-adjudicate **outcome**; **still** complete steps 2–4; step 5 **records** existing **B**/**H** |
| **RS-2** Settled open (**C**) | e.g. **DR-10**, **MD-06** | Full steps 1–4; step 5 **may not** adopt **B** without **§12** + **MD** reopen |
| **RS-3** Reopen candidate | **§12** **H** memo pending or maintainer accepted **Reasoned challenge** | **Freeze** new **B** on that sub-question until **§12** completes |
| **RS-4** Unaddressed | No **MD**/**DR** | Full CCRP; step 5 may propose **B** per §10 |

**Reasoned challenge:** Logged in step 6; **does not** suspend **B**/**H** unless maintainer moves sub-question to **RS-3**.

**Precedence:** Approved **MD** → Constitution **B/H** → traceability (audit map). **Conflict:** stop step 5; maintainer reconciliation memo.

## 2. Canon authority modes

| Mode | Definition |
|------|------------|
| **Inclusion (B)** | Text listed in Unified Canon layers (**DR-06**) |
| **Witness (B + procedural)** | Layer used in UC narrative, worship, CCRP—**layer-specific function** |
| **UC doctrine (B)** | Binds members after **MD** / **§12** |
| **Source-tradition (R)** | Authority **inside** Judaism, Christianity, Islam |
| **Binding UC teaching** | CCRP outcome with **binding** flag for **official** instruction |

**Receive:** UC **includes** canonical **witnesses** under CCRP; **does not** adopt every **R** claim of inspiration, inerrancy, or *taḥrīf*; **does not** resolve **DR-10** while **C**. UC recognition **≠** source traditions’ recognition of UC interpretation.

## 3. Evidence and **SD-*** source depth

**Classes:** **H**, **R**, **A** (motif only), **B**, **C**. **Never** use **A** for bibliographic depth.

| **SD-*** | Meaning |
|----------|---------|
| **SD-PRI** | Complete primary text read |
| **SD-ART** | Complete article or chapter read |
| **SD-EXC** | Substantial excerpt |
| **SD-ABS** | Abstract/metadata only |
| **SD-SEC** | Secondary summary |
| **SD-EXI** | Existence verified only |
| **SD-INA** | Inaccessible or unverified |

**Decisive step-4 minimums:** **H** (event) **SD-EXC** or **SD-PRI**; **H** (mss) **SD-ART**/**SD-EXC** or matrix **SD-SEC**; **R** dominant **SD-EXC** or **SD-SEC** survey; **R** minority if attested; **B** from **MD**/DR = **SD-PRI**; **RS-2** → **no new B**.

**Mixed bundles:** Decisive weight = weakest **decisive** leg; **SD-INA** cannot support **new B**. Label **unequal verification**—no false parity.

**DR-10 topics:** High-confidence **R** on *taḥrīf*/preservation requires **SD-EXC** primary tafsīr or **SD-ART** monograph; else **low-confidence** mandatory.

## 4. Steps 1–6

1. **Register** — Passages, translation, genres, claim types, **RS** per sub-question.  
2. **Context** — Language, setting, intertexts, chronicle/registry **H** limits.  
3. **Tradition survey** — Dominant **R**, attested minority, period/school, **strongest objection**, **ranking uncertainty** (**SD-*** cited).  
4. **Publish alternatives** — ≥2 serious options; evidence table; conflicting scholarship **both** listed.  
5. **UC ruling proposal** — **B** text if permitted, costs, classification; maintainer/council per §10; **MD-05** supersession optics.  
6. **Record** — Traceability ID; **dissent**; revision trigger.

## 5. Outcomes and deadlock

| Outcome | Binds members? |
|---------|----------------|
| Theological **C** | No **B** on topic |
| **Official UC teaching** | Yes, when **binding** flag set |
| **UC practice rule** | **B** + §12 if new |
| **Private inherited R** | No if §7.3 allows; **official** teaching must respect essential **H**/**B** |
| **Constitutional amendment** | §12 only |

**Deadlock:** No consensus → default **C**; no new **B** on **RS-2**. **H vs R** on past events: **H** binds history curriculum; **R** taught comparatively. **Split council:** **B** only with minority report.

**Pedagogy (**MD-09**):** Comparative teaching + **SD-*** assessment + explicit uncertainty—**not** DR-10 **B** while **MD-06** open.

**Teaching minimum (**MD-08**):** Official teachers present UC **H**/**B** accurately and **R** diversity without misrepresentation—**not** a universal worship affirmation test.
