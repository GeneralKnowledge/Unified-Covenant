## MD-07 — Preservation-first language

### Question

Should v0.3 §1 retain “**preserves inherited revelation where defensible**,” and if so how should it be read given **MD-06** and **DR-10** **C**?

### Existing constraints

- **MD-06:** No **B** on wholesale *taḥrīf* or wholesale denial; **C** open.  
- **§2.1:** Preservation-first **method** (not a preservation **conclusion**).  
- **Phase 6.8:** **L-2** flagged as **substantive communication risk**, not automatic **DR-10** closure.

### Options

| Option | Formulation (sketch) | Presentation vs substance |
|--------|-------------------|---------------------------|
| **A — Retain + explain** | Keep sentence; add cross-ref: “**defensible**” = §2.1 discipline; **does not** adopt **DR-10** **B** | **Presentation** if explanation is explicit; **risk** readers still hear “UC affirms preservation” |
| **B — Clarify inline** | Keep “preserves” but append “**without** settling scriptural preservation or *taḥrīf* (**MD-06**, **DR-10** **C**)” | **Presentation** + stronger **MD-06** signal; **reduces** ambiguity at cost of density |
| **C — Replace “preserves”** | “**Engages** inherited revelation using preservation-first method (**§2.1**)” | **Stronger methodological** identity; ** lowers** false preservation **R** inference; **does not** change **MD-06** status |

### Strongest objections

| Option | Objection |
|--------|-----------|
| **A** | Jewish/Christian readers may think UC endorses **R** preservation; Muslim readers may think UC denies *taḥrīf* polemic space |
| **B** | Long §1; still uses “preserves” which carries **R** echoes |
| **C** | Sounds less “reverent” to some; may be read as **walking back** commitment to scripture (though **DR-06** unchanged) |

### Further evidence / work

- None required for **A/B/C** choice itself; **DR-10** **B** still needs [Phase 6.5 options](../research/phase-6-5-tahrif-options.md) + **§12**.

### Explicit constraint

**No MD-07 option resolves DR-10 or replaces MD-06.**

## MD-08 — Public teaching and worship

### Question

What must UC **require** in **public teaching/worship** vs **allow privately** regarding **H** crucifixion (**DR-03**), **B** vindication (**DR-04**), and **R** readings (e.g. **DR-05** / 4:157)?

### Existing constraints

- **MD-02:** **H** crucifixion + **B** vindication; **not** “reconciled **R**.”  
- **§7.3:** Private 4:157 **R** allowed if **public teaching** respects **H** + **B**.  
- **§14:** **DR-03/04** **essential** membership.  
- **MD-05:** Non-supersession; integrity of other communities.

### Distinctions (must remain visible)

| # | Topic | Class | Typical locus |
|---|--------|-------|---------------|
| 1 | Crucifixion under Rome | **H** (**DR-03**) | History curriculum, public teaching |
| 2 | Vindication of the Anointed | **B** (**DR-04**) | Creed, worship |
| 3 | Inherited denial (4:157 **R**) | **R** description (**DR-05**) | Comparative mode |
| 4 | Public worship expression | **B** / **procedural** | Liturgy (mostly **C** / open) |
| 5 | Private inherited belief | **R** / conscience | **§7.3** |

### Options

| Option | Requirement | Religious freedom / membership |
|--------|-------------|------------------------------|
| **A — Minimal public accuracy** | Official UC materials **must not** deny **DR-03/04**; worship **may** vary if **not** contradicting essentials; **§7.3** unchanged | **Low** coercion; **risk** ambiguous worship |
| **B — Public worship affirmation** | Scheduled worship **includes** explicit **H+B** affirmation (e.g. creed line); private **R** still allowed silently | **Medium** communal pressure; clarifies UC identity |
| **C — Stronger membership articulation** | Members **must** be able to **articulate** **DR-03/04** when teaching **as UC**; optional periodic reaffirmation | **Higher** bar for **teachers/leaders**; may affect **dual identity** disclosure |
| **D — Worship = teaching floor (not ceiling)** | **B** only where **public worship** occurs; **study groups** may host **R** readings labelled **R** if **DR-03/04** stated first | Separates **liturgy** from **academic** comparative session |

### Strongest objections

| Option | Objection |
|--------|-----------|
| **A** | Visitors hear Muslim-member **private** **R** as UC norm |
| **B** | Muslim/Jewish members may feel worship **Christianised** |
| **C** | Conflates **teaching office** with **membership** if applied too broadly |
| **D** | Requires **discipline** definitions this docket **does not** invent |
