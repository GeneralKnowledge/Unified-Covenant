# Phase 6.12 — CCRP status taxonomy and binding procedure audit

**Status:** Procedural clarification. **Not** new doctrine.

**Baseline:** [ccrp-adopted.md](./ccrp-adopted.md) §1 (Phase 6.12). **Prior reports preserved:** [6-10](./ccrp-validation-6-10.md), [6-11](./ccrp-validation-6-11.md).

---

## Design choice

**Ambiguity found:** **RS-1** was defined as settled **B/H** only, while the scope table treated **MD-07–MD-11** (method, teaching, pedagogy, language, procedure) as **RS-1**—a **genuine modelling tension**, not mere wording.

**Options evaluated:**

| Option | Description |
|--------|-------------|
| **A** | Expand **RS-1** with mandatory **outcome kind** tags **B** / **H** / **G** |
| **B** | Separate procedure-status field parallel to **RS-1–RS-4** |

**Selected: Option A.** One status dimension (**RS-***) plus a **kind** tag avoids a parallel taxonomy, matches maintainer tables, and keeps registration in one step. **G** explicitly marks binding governance without implying substantive **B**/**H** on the merits.

---

## Revised rules (summary)

- **RS-1** = settled **outcome** (not “B/H only”); tag **B**, **H**, or **G**.
- **G** binds only the **procedural/governance** sub-question; **does not** settle **RS-2** theology on the same case.
- **RS-3** freezes new **substantive B** and new **H baseline** on the affected sub-question; amending **G** (CCRP text) uses **§12**, not ordinary CCRP overturn.
- **3A** records **RS**, **outcome kind**, scope; **3B**/**3C** unchanged from Phase 6.11.
