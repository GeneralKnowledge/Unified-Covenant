## Binding vs flexible

| Element | Class |
|---------|--------|
| Seven-part order and **B** spoken text in the liturgy file | **B** (MD-13) |
| Lectionary choice, CCRP publication, translation footnotes | **G** |
| Local welcome, service-project naming, silence length | **G** / **O** |
| Personal inherited **R** prayer elsewhere | **P** / **R** — not UC obligation |

---

## Before the gathering

1. State publicly that this is **UC** worship, not substitute synagogue/church/mosque (**MD-05**).
2. Select reading via **G** lectionary; complete CCRP record if required ([ccrp-case-record-md-13-liturgy.md](./ccrp-case-record-md-13-liturgy.md)).
3. For NT passion/vindication passages: teach **DR-03** **H**, **DR-04** **B**, **MD-12** bracket — no penal substitution **B**.

---

## During the gathering

- **MD-08:** Members may participate silently, partially, or by presence; no line-by-line verbal affirmation test.
- Use **witness** language (**MD-10**); avoid “fully preserved” while **DR-10** **C**.
- Do not adjudicate Q. 4:157 in the liturgy.

---

## Accessibility

- Provide translations (**G**); sense-preserving adjustment permitted for **B** paragraphs per v0.4.2 §8.2.
- Seating, length, and frequency: **G** (subject to **MD-14** when decided).
